# AenableOAuthSupportForAzurerchitecture Decision Records

We use [Architecture Decision Records (ADRs)](https://adr.github.io/) to capture significant design decisions in this prototype. Each ADR describes the context, the decision taken, and its consequences so future readers understand *why* the project is shaped the way it is.

## Format

ADRs follow a lightweight MADR-style template:

| Section | Purpose |
|---|---|
| **Status** | Proposed, Accepted, Deprecated, or Superseded |
| **Date** | When the decision was recorded |
| **Context** | Forces, constraints, and background |
| **Decision** | What we decided |
| **Consequences** | Positive, negative, and neutral outcomes |
